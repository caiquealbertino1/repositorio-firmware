# Repositorio de Firmware - Projeto Motiva

Arquivos utilizados pelo OTA da CP2:

- `version.json` - manifesto com a versao disponivel e URL direta do binario;
- `firmware_v1.ino` - codigo-fonte do Firmware 1.0;
- `firmware_v2.ino` - codigo-fonte do Firmware 2.0;
- `firmware_v2.bin` - binario compilado da V2 usado na atualizacao OTA.

URL do manifesto:
https://raw.githubusercontent.com/caiquealbertino1/repositorio-firmware/main/version.json

URL do binario:
https://raw.githubusercontent.com/caiquealbertino1/repositorio-firmware/main/firmware_v2.bin
